# generate-compilescripts.sh

Usage:

`bash generate-compilescripts.sh`

The script creates helper scripts to simplify compilation parameterization, which can then be launched as follows, for example:

`bash compile_c3_standalone.sh`

or

`./compile_c3_standalone.sh`

We can clean up the scripts when they are no longer needed:

`bash generate-compilescripts.sh --clean`
